Implementación de VisitsService. El contador se guarda en PostgreSQL y la deduplicación en Redis.

Parameters

mapper

conversor entidad → DTO.

repository

repositorio del contador.

redis

Redis, donde se guardan las huellas ya contadas (visits:fp:<huella>).

jwtSecret

clave HMAC para firmar los tokens (app.visits.jwt-secret). Tiene que tener al menos 32 bytes (256 bits), o la librería JWT la rechaza.

jwtMinutes

duración del token y de la ventana de deduplicación (app.visits.jwt-minutes, 15 por defecto).
