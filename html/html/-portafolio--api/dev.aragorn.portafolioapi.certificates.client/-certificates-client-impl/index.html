CertificatesClientImpl

@Component
class CertificatesClientImpl(@Qualifier(value = "certificatesRestClient") restClient: RestClient, @Value(value = "${app.certificates.base-url}") baseUrl: String) : CertificateClient

Implementación de CertificateClient que hace un GET a app.certificates.base-url.

El servicio de origen puede tardar o responder vacío la primera vez tras un rato inactivo, así que se reintenta hasta MAX_ATTEMPTS veces con backoff exponencial (1 s, 2 s, ...) en estos casos:

  • Respuesta 2xx sin cuerpo.

  • Error HTTP 5xx.

  • Error de red o timeout.

Sin reintento:

  • Lista vacía → CertificationEmptyException.

  • 404 → CertificationEmptyException.

  • Cualquier otro 4xx → se propaga el error HTTP original.
