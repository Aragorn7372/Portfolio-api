TechStackDetector

@Component
class TechStackDetector

Detecta las tecnologías de un repositorio a partir de sus rutas de fichero y, si hace falta, del contenido de unos pocos ficheros de configuración.

Es heurístico: no ejecuta ni compila nada, solo busca ficheros y directorios característicos. La detección se hace en dos fases para ahorrar peticiones a GitHub:

  1. selectContentFiles elige, a partir del árbol, qué ficheros merece la pena descargar.

  2. detect combina las rutas del árbol con el contenido de esos ficheros.
