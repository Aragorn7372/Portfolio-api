WebConfig

@Configuration
class WebConfig : WebMvcConfigurer

Configuración CORS de la API.

Solo permite llamadas desde los orígenes de app.host.allowed, con los métodos GET, POST y OPTIONS y con credenciales. Las credenciales hacen falta para que el navegador envíe la cookie visit_jwt en las peticiones entre dominios.

Spring Security aplica esta configuración gracias a cors(...) en SecurityConfig.
