HybridCacheManager

class HybridCacheManager(redisCacheManager: RedisCacheManager, localCaffeine: Cache<Any, Any>, redisTemplate: RedisTemplate<String, String>, codecs: Map<String, CacheJsonCodec> = emptyMap()) : CacheManager

CacheManager de dos niveles: una caché local en memoria (Caffeine, L1) delante de una caché distribuida en Redis (L2).

Cómo funciona

  • Lectura: primero se busca en L1. Si no está, se lee de L2 y, si existe, se copia a L1 para las siguientes lecturas.

  • Escritura: se guarda en L1 y en L2, y se publica un mensaje en el canal Redis cache:invalidate con el formato "<caché>:<clave>", para que las demás instancias descarten su copia local y no sirvan datos antiguos.

  • Tolerancia a fallos: si Redis no responde, las lecturas y escrituras se degradan a solo L1 y el error queda en el log. La petición no falla por un problema de caché.

Todas las cachés comparten la misma instancia de Caffeine. Para que no choquen claves iguales de cachés distintas, cada clave local se envuelve en un LocalKey con el nombre de la caché.

La instancia se crea en RedisConfig.cacheManager, que también decide qué cachés usan un CacheJsonCodec.

Parameters

redisCacheManager

gestor de Redis que proporciona la caché L2 de cada nombre, con su TTL.

localCaffeine

caché en memoria compartida que hace de L1.

redisTemplate

plantilla con la que se publican los mensajes de invalidación.

codecs

códec por nombre de caché. Las cachés sin códec guardan el valor tal cual.
