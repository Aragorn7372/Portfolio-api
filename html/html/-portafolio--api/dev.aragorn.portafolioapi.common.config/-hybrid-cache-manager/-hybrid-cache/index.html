HybridCache

class HybridCache(cacheName: String, localCaffeine: Cache<Any, Any>, redisCache: Cache, redisTemplate: RedisTemplate<String, String>, codec: CacheJsonCodec? = null) : Cache

Caché individual de dos niveles (L1 en memoria + L2 en Redis). Ver HybridCacheManager para la visión general.

Si tiene un codec, los valores se guardan en Redis como JSON y al leerlos se validan. Una entrada corrupta o con un tipo inesperado se considera "envenenada": se borra de ambos niveles y se trata como un fallo de caché, así el método cacheado vuelve a calcular el valor en lugar de devolver datos rotos.
